# Published component benchmarks

OpenPWR compares its **production point-kinetics and water-property functions** with independently published numerical values. This is equation verification and property-reference agreement. It is **not measured plant validation**: no claim is made that these checks establish the accuracy of a complete PWR, cold startup, plant protection settings, or operator procedures.

Run from the repository root with Node.js 22 or later:

```sh
npm run benchmark
npm test
```

The benchmark command writes `artifacts/benchmarks.json`. The evidence page reads the copy at `benchmarks.json` in the release build. The report contains each expected value, calculated value, absolute error, absolute tolerance, units, source URL/table, and initial conditions, together with release metadata. [`src/benchmarks.js`](../src/benchmarks.js) contains the transcribed reference data; expected values are never calculated by OpenPWR. Tests and benchmarks run offline with no package dependencies.

## Reference sets and acceptance criteria

| Reference | Cases included | Acceptance criterion | Interpretation |
| --- | --- | --- | --- |
| [Ganapol, CATS (2024)](https://arxiv.org/pdf/2406.11822), Tables 2a/b | Two negative step insertions, six published times per case from 0.1 to 200 s | 0.1% relative neutron-density error; 0.25 ms integration step | Production kinetics algorithm with the paper's TRI parameters |
| Same paper, Eq. 10 / Table 4 | Piecewise linear zigzag insertion; five published times from 0.5 to 10 s | 0.1% relative neutron-density error; 0.1 ms integration step | Time-dependent reactivity, with integration segmented at each slope change |
| [IAPWS R7-97(2012)](https://iapws.org/technical-guidance/release/IF97-Rev.download), Tables 5/15 | All three published test states in each implemented region; specific volume, enthalpy, internal energy, entropy, and isobaric heat capacity | Relative error ≤10⁻⁸, allowing for rounded published values | Original implementation of the region-1 and region-2 Gibbs equations |
| Same release, Table 35 | Saturation pressure at 300, 500, and 600 K | Relative error ≤10⁻⁸ | Region-4 pressure equation used when generating the production enthalpy cache |
| [NISTIR 5078, Table 1](https://www.nist.gov/document/nistir5078-tab1pdf) | Saturation pressure and liquid/vapor enthalpy at 20, 25, 100, 200, 280, 300, and 350 °C | Relative error ≤0.05% | Actual production functions, including the enthalpy cache; tolerance covers IF97/IAPWS-95 differences and table rounding |

There are 71 scalar comparisons: 17 kinetics, 33 direct IF97, and 21 NIST production-property comparisons. These are not 71 independent experiments. Multiple properties at one state are correlated, and the IAPWS test values are verification values generated by the defining equations. Consult the generated report for current results; a comparison count alone is not an accuracy measure.

## Kinetics problem specification

All included CATS cases use Thermal Reactor I, Appendix A, Table A.II (printed page 56):

| Group | βᵢ | λᵢ, s⁻¹ |
| --- | ---: | ---: |
| 1 | 0.000285 | 0.0127 |
| 2 | 0.0015975 | 0.0317 |
| 3 | 0.001410 | 0.115 |
| 4 | 0.0030525 | 0.311 |
| 5 | 0.000960 | 1.40 |
| 6 | 0.000195 | 3.87 |

The total delayed fraction is 0.00750; prompt generation time is 0.0005 s. Initially `n = 1` and all normalized precursor inventories `zᵢ = 1`, corresponding to equilibrium before insertion. External source and temperature feedback are zero. One dollar means reactivity equal to this benchmark's total delayed fraction. Thus −0.5 dollar and −1 dollar are −375 and −750 pcm, respectively.

For the zigzag, reactivity in pcm is `750t` through 0.5 s; `−750(t−0.5)+375` through 1 s; `750(t−1)` through 1.5 s; then 375 pcm. The expected values and times are copied from Table 4. The 100 s point, whose normalized neutron density is about 68 million, is outside the selected moderate-duration benchmark; it is not claimed as tested. The kernel is exercised independently of the coupled plant's power bounds.

The same `stepKinetics` function used by the plant accepts optional group data, generation time, and source. Defaults preserve the generic plant's own group data and generation time. For backward Euler, varying reactivity is evaluated at the right endpoint of the step. Every published edit time and zigzag corner is an integration boundary. No interpolation of neutron-density output is used.

The benchmark's fine timesteps are explicit. Passing at 0.1–0.25 ms **does not establish 0.1% accuracy at the interactive plant's maximum 50 ms step**, especially immediately after abrupt reactivity changes. The coupled plant has additional feedback, thermal integration, and controls. Separate time-refinement tests cover selected coupled transients, not all possible user actions. OpenPWR does not implement CATS or claim the paper's 10–12-digit solver precision.

### Excluded ambiguous ramp specification

The CATS preprint's Table 3a labels its positive ramp as TRII with a 0.0005 s generation time. Those conditions do not reproduce its listed values in the independently checked kinetics equations. The same numerical values appear in other published ramp comparisons, but with a different parameter description. Consequently this release excludes Table 3a rather than changing its stated parameters to fit its answers. The included Table 4 supplies an explicit waveform and consistent TRI parameters. This is a provenance limitation of the selected source entry, not a failed result hidden by widening the tolerance. A future addition should resolve the specification against an unambiguous primary source or author correction.

## Production thermodynamics

[`src/water-properties.js`](../src/water-properties.js) implements IAPWS region 1, region 2, and the region-4 saturation-pressure equation from the published coefficient tables. It is original Apache-2.0 code, with no imported property-library implementation. The general routines expose `v`, `h`, `u`, `s`, and `cp`; speed of sound, regions 3/5, metastable vapor, transport coefficients, and a general two-phase mixture equation of state are not implemented.

The plant's liquid/vapor enthalpy functions use saturated IF97 values cached at 0.25 °C spacing from 0 to 350 °C, with linear interpolation. Values are converted from kJ/kg to MJ/kg at the production API. This replaces the earlier quadratic liquid fit and Watson latent-heat approximation. The production pressure function retains the IAPWS saturation correlation from [SR1-86(1992)](https://iapws.org/technical-guidance/release/Supp-sat); both pressure formulations are explicitly checked, and no claim is made that they are identical.

Production steam-generator storage remains the reduced-order closure `E = Cmetal T + M h_liquid(T)`. A binary search locates the enthalpy-table interval; the linear storage equation is then inverted exactly within that interval. The forward and inverse functions therefore use the same interpolation. This numerical consistency does not make the lumped saturated-inventory closure a full steam-generator model. Feedwater enthalpy still uses saturated-liquid enthalpy as an approximation; primary coolant still uses an effective constant thermal capacity. The whole cycle is not an IF97 state-by-state Rankine calculation.

## Additional numerical checks

[`tests/benchmarks.test.js`](../tests/benchmarks.test.js) distinguishes the published comparisons from these internal verification tests:

- Kinetics time refinement against the same published negative-step and zigzag values must reduce maximum relative error when the step is halved.
- Every midpoint of the 1,320 production interpolation intervals spanning 20–350 °C is compared with direct IF97 evaluation. Liquid and vapor enthalpy errors must each stay below 0.01 kJ/kg at those sampled points. This is a dense numerical interpolation check, not a new independent physical reference or a mathematical global bound.
- Refining a separately constructed 1 °C interpolation to the production 0.25 °C grid must reduce the maximum sampled interpolation error by at least a factor of eight.
- Steam storage/inverse round trips cover exact 20/350 °C boundaries, nearby/off-grid temperatures, three inventory masses, and three metal capacities. Temperature error must be below 10⁻¹⁰ °C and energy error below 10⁻⁷ MJ. Out-of-table energy is rejected.
- A constant-source subcritical equilibrium is checked against the analytical balance `n = −SΛ/ρ`, with equilibrium precursors. This checks the cold-start source term; it does not validate startup physics or instrumentation.
- Unsupported property phases, nonfinite inputs, malformed group arrays, and invalid source/generation-time options are rejected.

The existing independent matrix-exponential kinetics checks, conservation checks, coupled time-refinement tests, and saved-state integrity checks remain in the suite. See [VALIDATION.md](VALIDATION.md) for their scope and the external plant evidence still needed. None of the cited authors or organizations endorses OpenPWR.
